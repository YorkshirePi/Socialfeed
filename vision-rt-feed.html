Feeds - one box per page/account, newest first

Pulled via the free public RSSHub service through a CORS proxy chain. YouTube uses the YouTube Data API directly when a key is set above (most reliable). Facebook and LinkedIn are usually fine; X and Instagram are often rate-limited on the public RSSHub instance and may show errors - the "Raw views per platform" panels lower down still show those directly.

Edit RSS source URLs

Swap any URL for your own RSSHub instance (e.g. https://your-host/...) or any other RSS feed. Leave blank to disable a source.
